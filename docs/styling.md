# تخصيص المظهر

يبدأ كل تطبيق بالمظهر المدمج: من اليمين إلى اليسار، بخط كوفي، ولون لازوردي، ومظهرين فاتح
وداكن يتبعان الجهاز. ويمكنك تغييره بثلاث طرق، من الأصغر إلى الأكبر:

1. **خيارات العنصر** تغيّر زراً واحداً أو بطاقة واحدة.
2. **السمة**، `سمة`، تغيّر لون التطبيق كله وخطه وزواياه.
3. **ملف تنسيقك الخاص** يفعل كل ما يفعله CSS، بالعناصر التي تعطيها `صنف`.

والثلاث تعمل كما هي في `dad dev` و`dad serve` و`dad build` و[الملعب](playground.md)، إلا ملف
التنسيق، فهو يحتاج ملفاً.

## خيارات العناصر { #options-on-elements }

| الخيار | العناصر | ما يأخذه |
|---|---|---|
| `نمط` | `زر` و`رابط` | `"أساسي"` (ممتلئ، وهو الأصل للأزرار)، `"ثانوي"` (بإطار)، `"خفيف"` (بلا إطار)، `"خطر"` (أحمر). وأي نمط يجعل الرابط يبدو زراً |
| `حجم` | `زر` و`رابط` و`فقرة` و`أيقونة` | `"صغير"`، `"عادي"`، `"كبير"` |
| `ملء` | `زر` | `صح`: بعرض العنصر الذي حوله |
| `لون` | `عنوان` و`فقرة` و`أيقونة` | لون للنص |
| `خلفية` | `عمود` و`صف` و`بطاقة` | لون، يظهر صبغة خفيفة خلف العناصر |
| `حشو` | `عمود` و`صف` و`بطاقة` | المسافة في الداخل، بالبكسل |
| `عرض` | `عمود` و`صف` و`بطاقة` | أقصى عرض، بالبكسل، والعنصر في الوسط |
| `محاذاة` | `عنوان` و`فقرة` | `"بداية"`، `"وسط"`، `"نهاية"` |
| `صنف` | كل العناصر | أسماء أصناف لـ[ملف تنسيقك الخاص](#your-own-stylesheet) |

```dad
بطاقة(خلفية: "ذهبي"، حشو: 24، عرض: 520) {
    عنوان("اشترك في النشرة"، محاذاة: "وسط")
    فقرة("يصلك كل جديد، مرة في الشهر."، لون: "باهت"، محاذاة: "وسط")
    زر("اشترك"، حجم: "كبير"، ملء: صح، أيقونة: "بريد") { اشترك() }
    زر("لاحقاً"، نمط: "خفيف") { أخف() }
}
```

### الألوان { #colours }

اللون اسم، أو قيمة مثل `"#1b2b6b"`. و`"أساسي"` لون التطبيق نفسه (انظر السمة أدناه)،

## سمة للتطبيق كله: `سمة` { #a-theme-for-the-whole-app }

اكتب `سمة` مرة واحدة في أعلى البرنامج:

```dad
سمة(اللون: "فيروزي"، الخط: "نسخ"، الزوايا: 14، العرض: 960)
```

| الخيار | ما يغيّره | القيم |
|---|---|---|
| `اللون` | اللون الرئيسي: الأزرار، والروابط، والتركيز، والخط تحت عناوين الصفحات. ويُختار نص الأزرار فاتحاً أو داكناً ليبقى مقروءاً | اسم لون أو `"#…"` |
| `الخط` | نوع الخط | `"كوفي"` (Noto Kufi Arabic، مدمج، وهو الأصل)، `"نسخ"` (خط نسخ على الجهاز، مثل Noto Naskh Arabic أو Geeza Pro)، `"النظام"` (خط الجهاز) |
| `الزوايا` | استدارة الزوايا، بالبكسل | من 0 إلى 40؛ والأصل 8 |
| `العرض` | أقصى عرض للصفحة، بالبكسل | من 320 إلى 2000؛ والأصل نحو 670 |
| `الحجم` | حجم النص، بالبكسل | من 12 إلى 28؛ والأصل 17 |
| `الوضع` | فاتح أو داكن | `"تلقائي"` (يتبع الجهاز، وهو الأصل)، `"فاتح"`، `"داكن"` |

والسمة تسري على كل الصفحات. وإن كُتبت `سمة` مرتين، فالعبرة بالأخيرة.

## ملف تنسيقك الخاص { #your-own-stylesheet }

ضع ملف CSS باسم برنامجك بجانبه: `app.css` للبرنامج `app.dad`. يحمّله `dad dev` و`dad serve`
بعد ملف التنسيق المدمج، ويعيد `dad dev` تحميل الصفحة حين تحفظه. وينسخه `dad build` إلى الموقع
باسم `style.css`.

وأعطِ العناصر أصنافه بـ`صنف`. وأسماء الأصناف يمكن أن تكون عربية:

```dad
بطاقة(صنف: "عرض-خاص") {
    عنوان("خصم الأسبوع")
}
```

```css
.عرض-خاص {
  border: 2px dashed var(--lapis);
  transform: rotate(-1deg);
}
```

وألوان ملف التنسيق المدمج متغيرات CSS تستعملها: `--lapis` (لون التطبيق)، و`--ink` (النص)،
و`--muted`، و`--paper` (الصفحة)، و`--surface`، و`--line`، و`--radius`. وللعناصر أصناف أيضاً،
مثل `.dad-card` و`.dad-table`.

وهذا ملف تنسيق `examples/09-library.dad`، يخفي الخط تحت عنوانه:

```css
--8<-- "examples/09-library.css"
```

## أيّها يغلب { #which-one-wins }

خيارات العنصر تخصه وحده، وتغلب السمة. وملف تنسيقك يأتي أخيراً، فيستطيع تغيير أي شيء،
والخيارات منها.
