# ٥. القوائم والقواميس

## القائمة

القائمة مجموعة قيم مرتبة، تُكتب بين قوسين مربعين:

```dad
ثابت الفواكه = ["تفاح"، "موز"، "برتقال"]

اطبع(الفواكه)
اطبع("عددها:"، الفواكه.عدد)
اطبع("الأولى:"، الفواكه[0]، "والأخيرة:"، الفواكه.آخر)
```

``` { .text .dad-out }
[«تفاح»، «موز»، «برتقال»]
عددها: 3
الأولى: تفاح والأخيرة: برتقال
```

- كل عنصر له **رقم** يبدأ من 0: `الفواكه[0]` هي «تفاح»، و`الفواكه[1]` هي «موز».
- `عدد` عدد العناصر، و`أول` و`آخر` أول عنصر وآخره.

### المرور على القائمة

```dad
ثابت الدرجات = [95، 72، 40، 88]

لكل د في الدرجات {
    اطبع("درجة:"، د)
}
```

``` { .text .dad-out }
درجة: 95
درجة: 72
درجة: 40
درجة: 88
```

### إضافة عنصر

القائمة في `ثابت` لا يتغير اسمها، لكن تستطيع أن تضيف إليها بـ`أضف`:

```dad
ثابت المشتريات = ["خبز"]
المشتريات.أضف("حليب")
المشتريات.أضف("تمر")
اطبع(المشتريات، المشتريات.يحتوي("تمر"))
```

``` { .text .dad-out }
[«خبز»، «حليب»، «تمر»] صح
```

## أن تسأل القائمة

هنا تظهر قوة الدوال المجهولة من الدرس الماضي. القائمة نفسها تعرف كيف تُرشَّح وتُحوَّل:

```dad
ثابت الدرجات = [95، 72، 40، 88، 55]

ثابت الناجحون = الدرجات.رشح { هو >= 50 }
اطبع("الناجحون:"، الناجحون)

ثابت مع_المكافأة = الدرجات.حول { هو + 5 }
اطبع("مع المكافأة:"، مع_المكافأة)

اطبع("المجموع:"، الدرجات.مجموع()، "المتوسط:"، الدرجات.مجموع() / الدرجات.عدد)
اطبع("مرتبة:"، الدرجات.رتب())
اطبع("أعلاها:"، أقصى(الدرجات)، "أدناها:"، أدنى(الدرجات))
اطبع("هل رسب أحد؟"، الدرجات.أي { هو < 50 })
```

``` { .text .dad-out }
الناجحون: [95، 72، 88، 55]
مع المكافأة: [100، 77، 45، 93، 60]
المجموع: 350 المتوسط: 70.0
مرتبة: [40، 55، 72، 88، 95]
أعلاها: 95 أدناها: 40
هل رسب أحد؟ صح
```

| تكتب | تحصل على |
|---|---|
| `ق.رشح { … }` | قائمة بالعناصر التي يصحّ عليها الشرط |
| `ق.حول { … }` | قائمة كل عنصر فيها بعد تحويله |
| `ق.عدد { … }` | كم عنصراً يصحّ عليه الشرط |
| `ق.أي { … }` و `ق.كل { … }` | هل يصحّ الشرط على عنصر واحد على الأقل؟ وعلى كل العناصر؟ |
| `ق.مجموع()` و `ق.رتب()` و `ق.عكس()` | المجموع، وقائمة مرتبة، وقائمة معكوسة |
| `ق.ضم("، ")` | نص فيه العناصر وبينها الفاصل |

وتستطيع أن تصل هذه الأسئلة بعضها ببعض:

```dad
ثابت الكلمات = ["ضاد"، "لغة"، "عربية"، "للبرمجة"]
اطبع(الكلمات.رشح { هو.طول > 3 }.حول { "«" + هو + "»" }.ضم(" و"))
```

``` { .text .dad-out }
«عربية» و«للبرمجة»
```

## القاموس

القاموس يربط **مفتاحاً** بـ**قيمة**، كما يربط دفتر الهاتف اسماً برقم:

```dad
متغير العواصم = ["مصر": "القاهرة"، "المغرب": "الرباط"]
العواصم["الأردن"] = "عمّان"

اطبع(العواصم["المغرب"])
اطبع(العواصم.عدد، العواصم.مفاتيح)
لكل البلد في العواصم {
    اطبع("عاصمة {البلد} هي {العواصم[البلد]}")
}
اطبع(العواصم["فرنسا"] ؟؟ "لا أعرف")
```

``` { .text .dad-out }
الرباط
3 [«مصر»، «المغرب»، «الأردن»]
عاصمة مصر هي القاهرة
عاصمة المغرب هي الرباط
عاصمة الأردن هي عمّان
لا أعرف
```

و`[:]` قاموس فارغ. وإن سألت القاموس عن مفتاح ليس فيه أعطاك `عدم`، أي «لا شيء». و`؟؟` تعني: «فإن كانت
عدماً فخذ هذه». وستعرف المزيد عن `عدم` في الدرس السابع.

## تمرين

1. لديك قائمة أسعار `[20، 3، 40، 8]`. اطبع الأسعار التي تزيد على 5 بعد إضافة ضريبة
   15٪ إلى كل منها، مقرّبة إلى خانتين عشريتين.
2. عُدّ كم مرة يتكرر كل حرف في كلمة «مممتاز» باستعمال قاموس.

??? note "الحل"

    ```dad
    ثابت الأسعار = [20، 3، 40، 8]
    اطبع(الأسعار.رشح { هو > 5 }.حول { (هو * 1.15).تقريب(2) })

    ثابت التكرار = [:] // قاموس فارغ
    لكل حرف في "مممتاز" {
        التكرار[حرف] = (التكرار[حرف] ؟؟ 0) + 1
    }
    اطبع(التكرار)
    ```

    ``` { .text .dad-out }
    [23.0، 46.0، 9.2]
    [«م»: 3، «ت»: 1، «ا»: 1، «ز»: 1]
    ```
