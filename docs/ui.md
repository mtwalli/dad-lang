# الواجهة

يمكن أن تكون لبرنامج ضاد واجهة: صفحات من مكونات (`مكون`) تحفظ حالتها (`حالة`) وترتّب
عناصر مثل `عمود` و`زر` و`حقل`. والصفحات من اليمين إلى اليسار وبخط عربي منذ البداية. شغّل
البرنامج بـ`dad dev` وافتح <http://localhost:8080>، أو جرّبه في [الملعب](playground.md).

```dad
مكون الرئيسية {
    حالة ع = 0
    عمود {
        عنوان("العدد: {ع}")
        زر("زد") { ع += 1 }
    }
}
```

اضغط **زد** فيتغير العنوان. ولا يلزم شيء آخر: لا HTML ولا JavaScript ولا خطوة بناء. وحين
تصير الصفحة جاهزة للمشاركة، يحوّلها `dad build` إلى موقع ثابت لا يحتاج خادماً (انظر
[البناء للويب](build.md)).

## المكونات: `مكون` { #components }

المكون دالة ترتّب جزءاً من الصفحة. ويأخذ معاملات كأي دالة، ويستعمل مكونات أخرى:

```dad
مكون عداد(اسم: نص، بداية: صحيح = 0) {
    حالة ع = بداية
    بطاقة {
        عنوان("{اسم}: {ع}"، مستوى: 2)
        صف {
            زر("زد") { ع += 1 }
            زر("أنقص"، معطل: ع == 0) { ع -= 1 }
        }
    }
}

مكون الرئيسية {
    عمود {
        عداد("التفاح")
        عداد("البرتقال"، بداية: 5)
    }
}
```

والبرنامج الذي لا [صفحات](#pages) فيه يعرض المكون الذي اسمه `الرئيسية` (أو `التطبيق`). فإن
لم يوجد، عرض آخر مكون لا يحتاج معاملات.

وداخل المكون يعمل الكود العادي كما يعمل في كل مكان: `إذا` تُظهر العناصر حين يصحّ شيء
فقط، و`لكل` تكررها.

```dad
إذا اسم != "" { فقرة("أهلاً يا {اسم}") }
لكل م في مهام { فقرة(م.عنوان) }
```

## الحالة: `حالة` { #state }

`حالة ع = 0` متغير يحفظ قيمته ما دامت الصفحة مفتوحة. ولا تُستعمل القيمة بعد `=` إلا أول
مرة. غيّرها في أي مكان، في كتلة زر مثلاً، فتعرض الصفحة القيمة الجديدة.

ولكل نسخة من المكون حالتها: العدّادان أعلاه يعدّان كلٌّ وحده. وتبقى الحالة ما دامت الصفحة
مفتوحة؛ ولتحفظ البيانات مدة أطول، احفظها في [جدول](server.md#tables).

## الصفحات: `صفحة` { #pages }

البرنامج الذي له أكثر من شاشة يعطي كل شاشة عنواناً بـ`صفحة`:

```dad
صفحة "/" = قائمة_المهام()
صفحة "/عن" = عن_التطبيق()
صفحة "/مهمة/{رقم}" = صفحة_المهمة(رقم)
```

وبعد العنوان يأتي ما تعرضه الصفحة، وهو مكون في الغالب. ويمكن أن يكون كتلة تُكتب كجسم
المكون، ولها `حالة` خاصة بها:

```dad
صفحة "/عن" {
    الشريط()
    عنوان("عن التطبيق")
    فقرة("مثال على برنامج من عدة صفحات.")
}
```

- **قيم من العنوان.** يأخذ `{رقم}` قيمته من العنوان: فالعنوان `/مهمة/3` يعرض
  `صفحة_المهمة(3)`. والأرقام تصير عدداً صحيحاً (`صحيح`)، وغيرها يبقى نصاً.
- **الروابط.** الرابط إلى إحدى الصفحات، مثل `رابط("عن التطبيق"، "/عن")`، يفتحها في
  مكانها دون إعادة تحميل. ويعمل زرّا الرجوع والتقدّم، ويمكن حفظ العنوان أو مشاركته.
- **الصفحة الحالية.** الرابط إلى الصفحة المعروضة يُميَّز (بخط عريض وتسطير في التنسيق
  المدمج)، فيصير صف الروابط شريط تنقّل. ضعه في مكون واستدعه أعلى كل صفحة:

    ```dad
    مكون الشريط() {
        صف {
            رابط("المهام"، "/")
            رابط("عن التطبيق"، "/عن")
        }
        فاصل()
    }
    ```

- **الانتقال من الكود.** `انتقل("/المهام")` ينقل إلى صفحة من كتلة زر، بعد الحفظ مثلاً.
  و`انتقل("https://…")` ينتقل إلى موقع آخر.

    ```dad
    زر("أضف") {
        ثابت م = أضف(الجديدة)
        انتقل("/مهمة/{م.رقم}")
    }
    ```

- **العنوان في المتصفح.** يعرض لسان المتصفح أول `عنوان` في الصفحة.
- **لا صفحة هنا.** العنوان الذي لا صفحة له يعرض صفحة تقول ذلك، وفيها رابط إلى الصفحة
  الرئيسية. ويجيبه `dad serve` بالرمز 404.
- **الحالة.** تبدأ كل صفحة بحالة جديدة حين تُفتح. وما يجب أن يبقى بين الصفحات مكانه
  [جدول](server.md#tables).

ولا تشترك صفحتان في عنوان واحد، ولا صفحة ومسار `مسار جلب`: الفاحص يقول ذلك. وليس لـ`صفحة`
هذا المعنى إلا قبل عنوان، فيمكن أن تبقى اسماً لمتغير. والبرنامج الذي لا `صفحة` فيه يعرض
مكونه الرئيسي عند `/` كما كان.

وهذا برنامج كامل بصفحاته، `examples/08-pages.dad`:

```dad
--8<-- "examples/08-pages.dad"
```

## العناصر { #elements }

| العنصر | ما يعرضه | مثال |
|---|---|---|
| `عمود` | ما بداخله، بعضه تحت بعض | `عمود { … }` |
| `صف` | ما بداخله، بعضه بجانب بعض من اليمين | `صف { … }` |
| `بطاقة` | مجموعة في إطار | `بطاقة { … }` |
| `عنوان` | عنوان؛ و`مستوى: 2` لعنوان أصغر | `عنوان("مهامي")` |
| `فقرة` | فقرة | `فقرة("مرحباً")` |
| `زر` | زر؛ تعمل كتلته عند الضغط عليه | `زر("أضف") { … }` |
| `حقل` | حقل نص يحرّر حالة | `حقل(اسم، تلميح: "اسمك")` |
| `مربع_اختيار` | مربع اختيار | `مربع_اختيار(م.منجزة) { … }` |
| `صورة` | صورة | `صورة("شعار.png"، وصف: "الشعار")` |
| `رابط` | رابط؛ وإلى إحدى [الصفحات](#pages) يفتحها في مكانها | `رابط("الموقع"، "https://…")` |
| `فاصل` | خط بين الأقسام | `فاصل()` |
| `قائمة_منسدلة` | قائمة منسدلة تختار قيمة حالة | `قائمة_منسدلة(اللون، ["أحمر"، "أخضر"])` |
| `اختيار` | مثلها، بأزرار اختيار | `اختيار(اللون، ["أحمر"، "أخضر"])` |
| `منطقة_نص` | حقل لنص أطول | `منطقة_نص(الملاحظات)` |
| `جدول_عرض` | سجلات في جدول | `جدول_عرض(مهمة.الكل())` |
| `قائمة_عناصر` | قائمة بنقاط أو بأرقام | `قائمة_عناصر(["أ"، "ب"])` |
| `ألسنة` و`لسان` | ألسنة | `ألسنة { لسان("الأول") { … } }` |
| `نافذة` | نافذة فوق الصفحة | `نافذة(مفتوحة) { … }` |
| `تنبيه` | رسالة بارزة | `تنبيه("تم الحفظ"، نمط: "نجاح")` |
| `أيقونة` | أيقونة | `أيقونة("بحث")` |
| `نموذج` | نموذج تفحص أزراره حقوله أولاً | `نموذج { … }` |

والخيارات معاملات مسماة:

| العنصر | الخيارات |
|---|---|
| `عمود` و`صف` و`بطاقة` | `محاذاة: "وسط"` (أو `"بداية"` أو `"نهاية"`)، و`مسافة: 24` (بالبكسل) |
| `عنوان` | `مستوى: 1` إلى `6` |
| `زر` | `معطل: صح`، و`أيقونة: "حفظ"`، و`إرسال: خطأ` (في نموذج: لا يفحص الحقول) |
| `حقل` | `تسمية: "…"` (عنوان فوقه)، و`تلميح: "…"`، و`صيغة: "رقم"` (أو `"نص"` أو `"كلمة_سر"` أو `"بريد"` أو `"تاريخ"` أو `"وقت"`)، و`أدنى` و`أقصى` (للأعداد والتواريخ)، و`معطل: صح`؛ وفي النموذج [قواعده](#forms) |
| `مربع_اختيار` | `نص: "…"` (تسمية بجانبه)، و`تسمية`، و`معطل: صح` |
| `قائمة_منسدلة` | `تسمية`، و`تلميح: "…"` (يظهر قبل الاختيار)، و`معطل: صح` |
| `اختيار` | `تسمية`، و`معطل: صح` |
| `منطقة_نص` | `تسمية`، و`تلميح: "…"`، و`أسطر: 6`، و`معطل: صح` |
| `نموذج` | مثل `عمود` |
| `جدول_عرض` | `أعمدة: ["…"]`، و`فارغ: "…"` (يظهر حين لا صفوف) |
| `قائمة_عناصر` | `مرقمة: صح`، و`فارغ: "…"` |
| `لسان` | `أيقونة: "…"` |
| `نافذة` | `عنوان: "…"` |
| `تنبيه` | `نمط: "نجاح"` (أو `"معلومة"` أو `"تحذير"` أو `"خطأ"`) |
| `أيقونة` | `وصف: "…"` (لقارئات الشاشة) |
| `صورة` | `وصف: "…"` (لقارئات الشاشة)، و`عرض: 120` |
| `رابط` | `أيقونة: "…"` |

وخيارات أخرى تغيّر شكل العنصر: `نمط` و`حجم` و`لون` و`خلفية` وغيرها، و`صنف` لملف تنسيقك
الخاص. وتشرحها صفحة [تخصيص المظهر](styling.md).

### الحقول { #fields }

أعطِ `حقل` حالةً فيحرّرها: ما تكتبه يصير في الحالة، وتغيير الحالة يغيّر الحقل.

```dad
حالة اسم = ""
حقل(اسم، تلميح: "ما اسمك؟")
فقرة("أهلاً يا {اسم}")
```

والحقل المربوط بحالة عددية (`حالة خطوة = 1`) حقل أعداد، وتبقى حالته عدداً. والكتلة بعد
الحقل تعمل عند كل تغيير، والنص الجديد فيها `هو`. والضغط على <kbd>Enter</kbd> في الحقل
يضغط الزر الذي بجانبه، أو زر [النموذج](#forms) الذي هو فيه.

### مربعات الاختيار { #check-boxes }

يأخذ `مربع_اختيار` صح أو خطأ. فإن أعطيته حالة غيّرها. وإن أعطيته قيمة أخرى، كحقل في سجل،
عملت كتلته والقيمة الجديدة فيها `هو`:

```dad
حالة مفعل = خطأ
مربع_اختيار(مفعل، نص: "الإشعارات")

مربع_اختيار(م.منجزة) { بدل(م) }
```

### الاختيار: `قائمة_منسدلة` و`اختيار` { #choices }

كلاهما يختار قيمة حالة من قائمة. `قائمة_منسدلة` قائمة تنسدل، و`اختيار` يعرض الخيارات أزرار
اختيار، وهو أنسب لخيارين إلى خمسة:

```dad
حالة اللون = "أخضر"
قائمة_منسدلة(اللون، ["أحمر"، "أخضر"، "أزرق"])
اختيار(اللون، ["أحمر"، "أخضر"، "أزرق"])
فقرة("اخترت {اللون}")
```

والخيارات أي قيم، لا نصوص فقط: أعداد، أو حالات `تعداد`، أو سجلات. تظهر الحالة باسمها، والسجل
بأول حقل نصي فيه، وتأخذ الحالة القيمة نفسها:

```dad
تعداد أولوية {
    منخفضة
    عادية
    عاجلة
}

حالة الأولوية = عادية
اختيار(الأولوية، [منخفضة، عادية، عاجلة])
```

وكما في `مربع_اختيار`، الكتلة بعد القائمة تعمل والاختيار الجديد فيها `هو`.

### نص أطول، وتواريخ وأوقات { #longer-text-dates-and-times }

`منطقة_نص` حقل لنص على عدة أسطر، كالملاحظات. و`حقل` مع `صيغة: "تاريخ"` أو `"وقت"` يعرض أداة
المتصفح لاختيار التاريخ أو الوقت، وتحفظ الحالة القيمة نصاً، مثل `"2026-10-21"` أو `"09:30"`.

```dad
حالة الملاحظات = ""
حالة الموعد = ""
منطقة_نص(الملاحظات، أسطر: 5، تلميح: "ملاحظات…")
حقل(الموعد، صيغة: "تاريخ"، أدنى: "2026-01-01")
```

## النماذج: `نموذج` { #forms }

ضع الحقول في `نموذج` وأعطها قواعد. فيفحص زرُّ النموذج كل حقل قبل أن تعمل كتلته: ما دام حقل
خاطئاً، يُظهر الزر الخطأ تحت كل حقل ولا يفعل شيئاً آخر. وحين تصح الحقول كلها تعمل الكتلة،
ويبدأ النموذج من جديد.

```dad
حالة الاسم = ""
حالة البريد = ""
حالة كلمة_السر = ""
حالة التأكيد = ""

نموذج {
    حقل(الاسم، تسمية: "الاسم"، مطلوب: صح، أدنى_طول: 2)
    حقل(البريد، تسمية: "البريد"، صيغة: "بريد"، مطلوب: صح)
    حقل(كلمة_السر، تسمية: "كلمة السر"، صيغة: "كلمة_سر"، أدنى_طول: 8)
    حقل(
        التأكيد،
        تسمية: "أعد كلمة السر"،
        صيغة: "كلمة_سر"،
        تحقق: { إذا هو == كلمة_السر { عدم } وإلا { "لا تطابق كلمة السر" } }
    )
    زر("أنشئ الحساب") { سجّل(الاسم، البريد) }
}
```

| القاعدة | الحقول | يكون الحقل خاطئاً حين |
|---|---|---|
| `مطلوب: صح` | كلها | يكون فارغاً، أو لم يُختر شيء من القائمة، أو لم يُحدَّد المربع |
| `أدنى_طول: 8`، `أقصى_طول: 200` | `حقل` و`منطقة_نص` | تقل أحرفه أو تزيد |
| `أدنى`، `أقصى` | `حقل` | يقل العدد أو التاريخ أو يزيد |
| `صيغة: "بريد"` | `حقل` | لا يكون بريداً إلكترونياً |
| `صيغة: "رقم"` | `حقل` | لا يكون عدداً |
| `تحقق: { … }` | كلها | تُرجع الكتلة نصاً، والقيمة فيها `هو`: ذلك النص هو الخطأ. وتُرجع `عدم` حين تصح القيمة |

والحقل الفارغ الذي ليس `مطلوب` صحيح، إلا ما يقوله `تحقق`. والأخطاء بالعربية، مثل «هذا الحقل
مطلوب» و«عدد الأحرف 8 على الأقل».

ويظهر خطأ الحقل حين تغادره، أو حين يُضغط زر النموذج، لا وأنت ما زلت تكتب في حقل لم تغادره.
وبعد الضغط ينتقل المؤشر إلى أول حقل خاطئ. والضغط على <kbd>Enter</kbd> في حقل يضغط زر النموذج.

- `تسمية: "…"` تضع عنواناً فوق الحقل، عليه * إن كان `مطلوب`. وتعمل خارج النماذج أيضاً.
- كل زر في النموذج يفحصه. والزر الذي لا ينبغي له ذلك، مثل «إلغاء»، يأخذ `إرسال: خطأ`.
- القواعد تعمل في `نموذج` فقط، والحقل خارجه مع `مطلوب` خطأ.
- يستطيع `تحقق` أن يستعمل حالات أخرى (ككلمة السر أعلاه) ودوال الخادم، مثل دالة تعرف هل
  البريد مستعمل. انظر `examples/10-signup.dad`.

## الجداول والقوائم { #tables-and-lists }

`جدول_عرض` يعرض قائمة سجلات في جدول، لكل حقل عمود. و`أعمدة` تختار الحقول وترتيبها، والشرطة
السفلية في الاسم تظهر مسافة. والكتلة بعده تضيف عموداً أخيراً فيه عناصر لكل صف، كالأزرار:

```dad
جدول_عرض(مهمة.الكل()، أعمدة: ["العنوان"، "منجزة"]، فارغ: "لا مهام بعد") { م =>
    زر("احذف"، نمط: "خفيف"، أيقونة: "حذف") { احذف(م) }
}
```

ويظهر صح علامة ✓، ولا يظهر شيء لخطأ وعدم. والجدول العريض يتمرر جانبياً على الهاتف.

و`قائمة_عناصر` تعرض قائمة بنقاط، أو بأرقام مع `مرقمة: صح`. وبلا كتلة يظهر كل عنصر نصاً، ومع
كتلة ترتّب الكتلة كل عنصر:

```dad
قائمة_عناصر(["الحليب"، "الخبز"، "التمر"])

قائمة_عناصر(مهمة.الكل()، مرقمة: صح) { م =>
    رابط(م.العنوان، "/مهمة/{م.رقم}")
}
```

وكلاهما يعرض `فارغ` (أو «لا شيء لعرضه بعد.») حين تكون القائمة فارغة.

## الألسنة: `ألسنة` { #tabs }

داخل `ألسنة` لكل `لسان` عنوان وعناصر يعرضها، ولا يُرتَّب إلا اللسان المفتوح. ويُحفظ اللسان
المفتوح كأنه `حالة`؛ أعطِ حالة معاملاً أول لتختاره من الكود، برقمه (من 0) أو بعنوانه:

```dad
حالة اللسان = "الإعدادات"
ألسنة(اللسان) {
    لسان("الحساب"، أيقونة: "مستخدم") {
        فقرة("بياناتك")
    }
    لسان("الإعدادات"، أيقونة: "إعدادات") {
        فقرة("الإعدادات")
    }
}
```

ومفاتيح الأسهم تنتقل بين الألسنة.

## النوافذ: `نافذة` { #dialogs }

`نافذة` تعرض عناصرها فوق الصفحة ما دامت حالتها صح. وزر × ومفتاح <kbd>Esc</kbd> والضغط خارجها
تعيد الحالة إلى خطأ:

```dad
حالة مفتوحة = خطأ
زر("احذف الكل"، نمط: "خطر") { مفتوحة = صح }
نافذة(مفتوحة، عنوان: "هل أنت متأكد؟") {
    فقرة("ستُحذف كل المهام.")
    صف {
        زر("احذف"، نمط: "خطر") {
            امسح_الكل()
            مفتوحة = خطأ
        }
        زر("إلغاء"، نمط: "ثانوي") { مفتوحة = خطأ }
    }
}
```

## التنبيهات والأيقونات { #alerts-and-icons }

`تنبيه` رسالة بارزة، بأيقونة تناسب نوعها: `"معلومة"` (الأصل)، أو `"نجاح"` أو `"تحذير"` أو
`"خطأ"`. وتعلن قارئات الشاشة التحذيرات والأخطاء فوراً.

```dad
تنبيه("حُفظت التغييرات."، نمط: "نجاح")
تنبيه("ستنتهي الجلسة بعد دقيقة."، نمط: "تحذير")
```

و`أيقونة` تعرض أيقونة باسمها العربي. والأزرار والروابط والألسنة تأخذ أيقونة أيضاً قبل نصها،
بالخيار `أيقونة`. والأيقونة وحدها زينة؛ أعطها `وصف` حين تحمل معنى، لتنطقه قارئات الشاشة.

```dad
أيقونة("بحث"، وصف: "بحث")
زر("احفظ"، أيقونة: "حفظ") { احفظ() }
رابط("الإعدادات"، "/الإعدادات"، أيقونة: "إعدادات")
```

## كيف تعمل { #how-it-runs }

في `dad dev` و`dad serve` تعمل المكونات على الخادم. ترسل الصفحة في المتصفح كل ضغطة وتغيير
إلى البرنامج، فيشغّل البرنامج الكتلة ويرتّب الصفحة من جديد، وتتحدّث الصفحة في مكانها
محتفظة بالتركيز وبما تكتبه. وهكذا يعمل Phoenix LiveView وBlazor Server. والروابط إلى
الصفحات تعمل بالطريقة نفسها: يرتّب البرنامج الصفحة الجديدة، ويعرض المتصفح عنوانها. ومع
[`dad build`](build.md) تُترجم المكونات نفسها إلى JavaScript وتعمل في المتصفح بلا خادم،
وتكون عناوين الصفحات مثل `index.html#/عن`. والبرنامج واحد في الحالتين.

ويأتي الشكل من ملف تنسيق مدمج: من اليمين إلى اليسار، بخط Noto Kufi Arabic، وبمظهرين فاتح
وداكن يتبعان إعداد الجهاز. ويمكنك تغييره لعنصر واحد أو للتطبيق كله: انظر
[تخصيص المظهر](styling.md).

وحين تحفظ الملف يعيد `dad dev` تحميل البرنامج، وتُعاد الصفحة معه. وتبقى البيانات في
الجداول، أما الحالة فتبدأ من جديد. والأخطاء في الكتل تظهر أسفل الصفحة.
